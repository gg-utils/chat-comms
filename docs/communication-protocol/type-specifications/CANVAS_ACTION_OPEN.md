# CANVAS_ACTION_OPEN Specification

## Specification

### Type Definition

`CANVAS_ACTION_OPEN` is an action type that opens the canvas interface, providing a secondary workspace for displaying detailed information, complex data visualizations, and interactive content that would be too large or complex for the chat interface.

### Example Full Action Payload

**Action Payload**

```json
{
  "action_id": "string", // required - unique identifier for the action
  "action_type": "CANVAS_ACTION_OPEN", // required - must be exactly this value
  "action_data": {
    "target": "CANVAS", // required - must be "CANVAS"
    "canvas_id": "string", // optional - ID of the canvas document to open or create
    "canvas_title_label": "string", // optional - initial title for the canvas
    "canvas_title_href": "string", // optional - URL that makes the canvas title clickable
    "canvas_state": "string", // optional - initial canvas state
    "canvas_icon": "string", // optional - initial canvas icon identifier
    "canvas_initial_contents": "array" // optional - initial canvas contents to display
  }
}
```

### Properties

| Property                              | Type   | Required | Description                                                                            |
| ------------------------------------- | ------ | -------- | -------------------------------------------------------------------------------------- |
| `action_id`                           | string | Yes      | Unique identifier for this action (must follow action_id convention)                   |
| `action_type`                         | string | Yes      | Must be `"CANVAS_ACTION_OPEN"`                                                         |
| `action_data.target`                  | string | Yes      | Must be `"CANVAS"`                                                                     |
| `action_data.canvas_id`               | string | No       | ID of the canvas document to open or create                                            |
| `action_data.canvas_title_label`      | string | No       | Initial title for the canvas                                                           |
| `action_data.canvas_title_href`       | string | No       | URL that makes the canvas title clickable, opening the URL when clicked                |
| `action_data.canvas_state`            | string | No       | Initial canvas state: `"DEFAULT"`, `"LOADING"`, `"PROCESSING"`, `"ERROR"`, `"SUCCESS"` |
| `action_data.canvas_icon`             | string | No       | Initial canvas icon identifier                                                         |
| `action_data.canvas_initial_contents` | array  | No       | Array of initial canvas content objects to display                                     |

## Canvas States

- **`DEFAULT`**: Normal operational state
- **`LOADING`**: Canvas is loading data or content
- **`PROCESSING`**: Canvas is performing operations
- **`ERROR`**: Canvas encountered an error
- **`SUCCESS`**: Canvas completed operations successfully

## JSON Schema Definition for `action_data`

The `action_data` for `CANVAS_ACTION_OPEN` adheres to the following schema:

```json
{
  "type": "object",
  "required": ["target"],
  "properties": {
    "target": {
      "type": "string",
      "enum": ["CANVAS"],
      "description": "Target interface for the action, must be CANVAS."
    },
    "canvas_id": {
      "type": "string",
      "description": "Optional ID of the canvas document to open or create. If omitted, a new unique ID may be generated by the UI."
    },
    "canvas_title_label": {
      "type": "string",
      "description": "Optional initial title for the canvas. Defaults to a generic title if omitted."
    },
    "canvas_title_href": {
      "type": "string",
      "description": "Optional URL that makes the canvas title clickable. When provided, clicking the canvas title opens this URL."
    },
    "canvas_state": {
      "type": "string",
      "enum": ["DEFAULT", "LOADING", "PROCESSING", "ERROR", "SUCCESS"],
      "default": "DEFAULT",
      "description": "Optional initial canvas state. Defaults to DEFAULT."
    },
    "canvas_icon": {
      "type": "string",
      "description": "Optional initial canvas icon identifier. UI may use a default if omitted."
    },
    "canvas_initial_contents": {
      "type": "array",
      "description": "Optional array of initial canvas content objects to display. Canvas opens empty if omitted.",
      "items": {
        "type": "object",
        "description": "A ChatComms_RuntimeChat_CanvasContent object. Refer to ChatComms_RuntimeChat_CanvasContent type definitions for structure.",
        "required": ["content_id", "content_type", "content_data"],
        "properties": {
          "content_id": { "type": "string" },
          "content_type": { "type": "string" },
          "content_data": { "type": "object" }
        }
      }
    }
  }
}
```

### Supported Initial Content Types

Items in `canvas_initial_contents` can be any valid ChatComms_RuntimeChat_CanvasContent type, including:

- `CANVAS_CONTENT_MARKDOWN`
- `CANVAS_CONTENT_SECTION`
- `CANVAS_CONTENT_HTML` (renders raw HTML; no sanitization performed by the protocol)

**Example: Open with HTML content**

```json
{
  "action_type": "CANVAS_ACTION_OPEN",
  "action_data": {
    "target": "CANVAS",
    "canvas_initial_contents": [
      {
        "content_id": "intro-html",
        "content_type": "CANVAS_CONTENT_HTML",
        "content_data": { "html": "<h1>Welcome</h1><p>Intro content.</p>" }
      }
    ]
  }
}
```

### Default Behaviors for Optional Parameters

- **`canvas_id`**: If omitted, a new unique ID will be generated by the UI for the canvas instance. This means subsequent actions cannot target this specific canvas instance by ID unless the UI communicates this generated ID back to the assistant or stores it for future reference.
- **`canvas_title_label`**: If omitted, the UI may use a default title (e.g., "Canvas", "Workspace") or leave the title area blank.
- **`canvas_title_href`**: If provided, the canvas title becomes clickable and opens the specified URL when clicked. This can be used to link to external resources, documentation, or related content.
- **`canvas_state`**: If omitted, defaults to `"DEFAULT"`.
- **`canvas_icon`**: If omitted, no icon will be displayed, or a default canvas icon may be used by the UI.
- **`canvas_initial_contents`**: If omitted or an empty array is provided, the canvas will open empty, ready for content to be added via subsequent `CANVAS_ACTION_UPDATE` actions.
